# app-pages

GitHub Pages structure for Tendora, Ingredia and LexWriter.

## Before publishing

1. Replace every occurrence of `YOUR_SUPPORT_EMAIL` with your real support email.
2. Review each Privacy Policy so it matches the actual app behavior, permissions, analytics, SDKs, APIs and data storage.
3. Upload the full folder contents to the root of your GitHub repository.
4. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
5. Test every Privacy, Support and Terms link in a browser.

## Expected GitHub Pages URLs

Assuming the repository is named `app-pages`:

- `/app-pages/tendora/privacy/`
- `/app-pages/tendora/support/`
- `/app-pages/tendora/terms/`
- `/app-pages/ingredia/privacy/`
- `/app-pages/ingredia/support/`
- `/app-pages/ingredia/terms/`
- `/app-pages/lexwriter/privacy/`
- `/app-pages/lexwriter/support/`
- `/app-pages/lexwriter/terms/`

Note: These templates are practical starting points and are not legal advice.
