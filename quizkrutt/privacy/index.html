Spilldata blir på enheten

Appen har ingen annonser, sporing eller tredjeparts analyseverktøy og sender ingen spilldata til Quizkrutt-serveren. Nettduell er ikke aktiv i denne versjonen.

Fremdrift, pakkehistorikk og innstillinger lagres på enheten. Sofaduellens kallenavn og svar beholdes bare mens duellen pågår. De seks første quizpakkene følger med appen; å legge dem til sender ingen data. Fra versjon 0.6.0 kan du velge å hente en offentlig pakkekatalog og nye quizpakker fra GitHub Pages. GitHub mottar da vanlige forbindelsesopplysninger, som IP-adresse og forespurt fil, for å levere innholdet. Ingen spillresultater, svar eller kallenavn sendes med disse nedlastingene. Nedlastede pakker og katalogen lagres lokalt og kan brukes uten nett. Solo og sofaduell krever ingen konto.

Enhetens sikkerhetskopiering kan omfatte lokale appdata etter dine Apple-innstillinger. Appen synkroniserer ikke spilldata med nettversjonen. Hvis du sletter appen, kan lokal fremdrift gå tapt.

Når du kontakter oss

Hvis du sender e-post eller TestFlight-tilbakemelding, behandler vi innholdet og kontaktopplysningene du oppgir for å besvare henvendelsen og rette feil. E-post behandles gjennom e-postleverandøren. Apple behandler TestFlight- og diagnostikkinformasjon etter Apples regler. Ikke send passord eller innloggingskoder.

Vi bruker supportopplysninger for å følge opp henvendelsen og forbedre appen, basert på vår berettigede interesse i å tilby support. Vi oppbevarer henvendelser så lenge det er nødvendig for oppfølging.

Dine spørsmål og rettigheter

Kontakt oss ved spørsmål, ønsker om innsyn, retting eller sletting av henvendelser, eller dersom du vil protestere mot behandlingen. Du kan klage til Datatilsynet. Lokale spilldata administreres på enheten.

Dette nettstedet

Disse support- og personvernsidene leveres via GitHub Pages. Nettleseren sender vanlige forbindelsesopplysninger, som IP-adresse og forespurt side, til hostingtjenesten for å levere sidene. Vi har ikke lagt inn analyseverktøy, annonser, skjemaer eller informasjonskapsler i sidene. Hostingtilbyderen kan behandle tekniske drifts- og sikkerhetslogger etter sine regler.

Fremtidige versjoner

Før nettduell aktiveres, oppdateres informasjonen om server, innlogging, databehandlere, lagringstider og sletting. Denne erklæringen beskriver betaen med lokalt spill og valgfri nedlasting av quizpakker.
